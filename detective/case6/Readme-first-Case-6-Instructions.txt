Use Adobe Acrobat Reader or similar program to open the files.

We highly recommend using the "Fit one full page to window" mode.

Start playing Case 6 by reading Case 6 Introduction (Detective-Case-6-Introduction.pdf)

Open Detective-Case-6-Cards.pdf to get access to the cards.

There are 23 cards and one cover card (pages 600 and B600). Each card has the front side and the back side. Each card number (e.g. #601) corresponds with a PDF page number (e.g. 601). To go to the back side of a card, please type "B" before the card number (e.g. B601).
